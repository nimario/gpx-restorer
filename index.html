GPX/TCX 고도를 스트라바 기반으로 보정하거나, 라이딩가즈아가 망가뜨린 원본 고도를 복원합니다

사용 방법

GPX 파일의 고도 정보를 스트라바 기반의 고도 정보로 보정합니다. 실제 사용자들이 기록한 데이터를 기반으로 하기 때문에, 위성 지도 근사값보다 정확한 경우가 많습니다.

  1. 고도를 보정하고 싶은 GPX/TCX 파일 업로드
  2. 현재 고도·웨이포인트 확인, 필요하면 이름/유형 수정·삭제나 오르막 자동 감지
  3. 보정 시작 클릭
  4. 결과 확인 후 코스 이름·내보낼 형식 지정
  5. GPX 또는 TCX 다운로드

⚠️ 이 결과를 라이딩가즈아에서 다시 만지면 고도가 또 뭉개집니다. 그럴 계획이면 그 이후엔 ② 탭으로 오세요.

① 탭으로 이미 보정한 파일을 라이딩가즈아에서 다시 편집했다면, 정확히 이 상황이라 ①을 또 돌릴 필요 없이 여기서 바로 복구됩니다.

  1. 라이딩가즈아에서 웨이포인트 작업까지 마친 GPX/TCX 업로드
